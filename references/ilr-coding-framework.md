# ILR Coding Framework (CC#1–CC#8)

> Internal reference for Study 1 (ILR). Source: `20260702_ILR_Coding_Framework_.docx`.
> Used to support the critical analysis stage (Torraco, 2016b). Coding proceeds at the
> level of these categories rather than by verbatim extraction.

**Research context**
- Overarching question: How does misalignment between electoral cycles and megaproject timelines shape megaproject governance?
- RQ1: How is temporal misalignment conceptualised in a megaproject context?

| Code | Category | Type | What it captures |
|---|---|---|---|
| CC#1 | Temporal terminology | Free text | Temporal terms used in the source. For each term, note whether it is **primary** (the source develops it as its own contribution) or **borrowed** (used from another author, with source noted). Distinguish terms grounded in temporality theory from context-specific terms describing empirical temporal phenomena. |
| CC#2 | What is misaligned | Free text | Description of the tension (context). The type(s) of temporality-related misalignment present. One source may contain more than one type; record each separately. |
| CC#3 | Actors | Free text | Who experiences, is involved in, or produces the misalignment. Based on Zwikael and Meredith (2018) ten core project roles (funding roles: champion, project steering committee, project funder, project owner, user; performing roles: PMO, project manager, project sponsor, programme manager, project team), with possible extended roles (political actor, civil society organisation, affected community, media, judiciary) and any additional role found in the data. |
| CC#4 | Level of misalignment | Free text | Supranational / National / Programme / Project / Inter-organisational / Actor / Community-Local / Not available. Record all levels involved (multiple allowed). Cross-level misalignment is coded by listing each level it spans (e.g., "National; Project"). |
| CC#5 | Cause of misalignment | Free text | Derived from the source, using the source's own language where possible. Note any form of political temporality: electoral cycle, budgetary rhythm, legislative cycle, administrative transition, judicial temporality, policy window, partisan political rhythm, international political cycle, or other. Open to revision as coding proceeds. |
| CC#6 | Responses to misalignment | Free text | What actors do or do not do in response. |
| CC#7 | Outcomes of misalignment | Free text | Outcomes may include (illustrative, not exhaustive): delivery, cost, scope, project continuation or cancellation, value, legitimacy, sustainability, trust, accountability. Note whether the source links the outcome to the misalignment explicitly or implicitly, or whether it could have other causes. |
| CC#8 | What is left unexplained | Free text | Theoretical, Empirical, Electoral. **Electoral must be filled for every source** (Present / Not addressed). |

## Notes

- The framework is applied during full-text analysis of the 77 sources forming the analytical sample (10 analysed so far; analysis of the remainder ongoing).
- Coding is category-level, supporting concept integration rather than pattern cataloguing.
- The framework is open to revision as coding proceeds (CC#5 in particular), consistent with the iterative logic of the integrative review (Cronin & George, 2023; Torraco, 2016b).
